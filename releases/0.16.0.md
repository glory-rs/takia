# Takia 0.16.0

Layout cache lookups now take a shared reference. Implementors of
`CacheTree` should change the receiver of `cache_get` to `&self`.
An atomic eviction clock lets shared readers record cache hits. The transient
layout cache no longer implements Serde serialization.

This release also improves node-context lookup and corrects block layout for
collapsed margins, floats and percentage widths on replaced children.
