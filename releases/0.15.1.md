# Takia 0.15.1

Coordinated engine release for Glory and Sapid 0.6.1.

- Requires Rust 1.95 and uses Cargo workspace resolver 3.
- Updates compatible dependencies while retaining the maintained layout engine,
  including fractional flex-space and sizing behavior used by Glory.
- Keeps the optional parser, serialization and allocation features explicit.
- Retains upstream history, copyright and license notices under the Takia name.

The release workflow runs all-feature tests and a no-default-features library
check before uploading. Registry consumers use the published `takia = "=0.15.1"`
dependency; no sibling checkout or Cargo patch is required.
